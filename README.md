# 日文複習專案（jp-learn）

把「來學日本語」的**課本、老師講義、上課板書照片**，整理成結構化資料，
自動產生**可在電腦／手機上複習的網頁**與 **Anki 牌組**，並能逐課持續擴充。

---

## 🚀 快速開始

### 電腦上（最簡單）

- **Windows**：在資料夾裡**雙擊 `start.bat`**
- **macOS / Linux**：在終端機執行 `./start.sh`（或 `python3 start.py`）

啟動器會自動：
1. 檢查 Python、**自動安裝缺少的套件**
2. 產生最新的複習資料
3. 開啟瀏覽器到複習網頁

> 需要先安裝 [Python 3.8+](https://www.python.org/downloads/)（安裝時請勾選「Add Python to PATH」）。

### 手機 / 平板上

1. 手機和電腦連到**同一個 Wi-Fi**
2. 在電腦執行上面的啟動器
3. 終端機會顯示一個**手機網址**（像 `http://192.168.x.x:5599/`）和 **QR code**
4. 用手機相機掃 QR code，或直接輸入那個網址即可複習

> 第一次啟動，Windows 可能跳出防火牆提示，請選「**允許存取**」，手機才連得到。

---

## 📱 複習網頁怎麼用

| 分頁 | 功能 |
|------|------|
| **說明** | 每課的導讀、學習目標、重點筆記（一進來先看，快速進入狀況） |
| **單字卡** | 翻卡複習；可只看不評分（按「下一個」）；🔀 **自動隨機播放**整課單字、自動發音 |
| **文法** | 還原老師講義版面：文型 → 接続 → 説明 → 例 →【練習】（答案可隱藏/顯示自我測驗） |
| **測驗** | 中→日 隨機出題（單字＋文法練習） |

其他：
- 🔊 **語音播放**：例句、單字卡都能點喇叭聽日語發音
- ⚙️ **設定**（右上齒輪）：深色模式、自動播放的「播放次數／間隔秒數／語速」
- 上方可勾選**只複習某幾課**（預設只選最新一課）

### Anki（手機零碎時間背單字）
匯入 `exports/anki_vocab.tsv`、`exports/anki_grammar.tsv`
（匯入時欄位分隔選「**Tab／製表符**」、勾選「允許 HTML」）。
卡片會帶 `課代碼`／`文法`／`会話`／`重点` 標籤，可在 Anki 篩選。

---

## ➕ 新增一課（持續擴充）

課數依冊編號，檔名 `B<冊>L<課>`，例如第三冊第4課＝`B3L04`。

1. 把該課照片放到 `raw/B3L04/`（課本內頁、講義、板書都可以）
2. 請 Claude：「**匯入第三冊第4課**」 → 由 Claude 辨識照片、整理成 `data/lessons/B3L04.yaml`
   （補假名、中文翻譯、依講義結構整理文型與練習、標好文法課／會話課來源）
3. 重新執行啟動器（或 `python scripts/build.py`）即可看到新內容

資料格式詳見 [SCHEMA.md](SCHEMA.md)。

## 📁 專案結構

```
jp-learn/
├── start.bat / start.sh / start.py   啟動器（自動安裝套件＋開網站）
├── requirements.txt                  需要的 Python 套件
├── data/
│   └── lessons/*.yaml                每課的內容（唯一資料來源，可手動編輯）
├── scripts/build.py                  把 YAML 編譯成網頁資料與 Anki 檔
├── web/                              複習網頁（HTML/CSS/JS，純前端）
├── exports/                          Anki 匯入檔（自動產生）
├── raw/                              原始照片備份（依課存放）
├── SCHEMA.md                         資料格式說明
└── README.md
```

## 🛠️ 疑難排解

| 狀況 | 解法 |
|------|------|
| 雙擊 bat 閃一下就關 | 代表沒裝 Python，或沒勾「Add to PATH」。重裝 Python 並勾選該選項 |
| 手機連不到 | 確認同一 Wi-Fi；Windows 防火牆要按「允許」；公司／公共 Wi-Fi 常會擋裝置互連 |
| 埠號被占用 | 改用其他埠：`python start.py --port 8080` |
| 套件裝不起來 | 手動執行 `pip install -r requirements.txt` |
| 匯入 HEIC 照片 | 需要 `pillow-heif`（`pip install pillow-heif`），一般複習用不到 |

## 🧰 技術說明

- **資料層與複習層分離**：所有複習材料都由 `data/lessons/*.yaml` 自動生成，改內容只需改 YAML。
- 複習網頁是**純前端**（不需後端、不需網路），啟動器只是用 Python 內建伺服器把它分享到區網讓手機連。
- 語音用瀏覽器內建日語 TTS（Chrome／Edge／Safari 效果最佳）。
